
# Terminal set up

```bash
curl -fsSL https://cli.kiro.dev/install | bash
```
if unzip not found
```bash
sudo apt update
sudo apt install unzip -y
```

after installation to update your path to include the local bin
```bash
export PATH="$HOME/.local/bin:$PATH"
```

to see that everything is working
```bash
kiro-cli --version
```
