# What is Cloud Computing?
Това е предлагането на computing услуги колкото ти трябва и когато ти трябва с гъвкаво плащане.
## Cloud deployment types

1-Cloud based deployment
2- On premise deployment
3- Hybrid deployment

## Benefits of the AWS Cloud
1-Trade fixed expense for variable expense
	Ти имайки сървър ще плащаш фиксирана цена за наемането му или за поддръжката му. А с AWS цената ти прямо каквото ползваш.
2-Benefit from massive economies of scale
	AWS закупувайки дата центрове те намаляват цената за вдигането на тези центрове драстично поради цените на които изкупуват техниката.
3-Stop guessing capacity
	Не трябва да налочваш какъв трафик ще има услугата ти.
4-Increase speed and agility
	По бързо разгъване на нови версии и сервизи.
5-Stop spending money to run and maintain data centers
	Не плащаш за поддръжка на хардуера а само как го ползваш.
6-Go global in minutes
	AWS предоставя възможноста да си най-близи сервизите ти до клиента. Тоест ако желаеш да разрасне клиентската ди демографи то това се прави за секунди ползвайки AWS.
